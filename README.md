# 📝 To-Do List Application (Python CLI)

A simple yet effective command-line To-Do List application built using Python.  
This project helps users manage daily tasks efficiently by allowing them to add, view, and delete tasks in an organized way.

---

## ✨ Features

- ➕ Add new tasks easily
- 📋 View all saved tasks
- ❌ Delete completed or unwanted tasks
- 🔁 Simple menu-driven interface
- ⚡ Fast and lightweight CLI application

---

## 🛠️ Technologies Used

- Python 🐍
- Lists & Functions
- File Handling (if used in future upgrade)
- Command Line Interface (CLI)
